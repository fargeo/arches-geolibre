Arches for GeoLibre

Load, edit and create Arches resource geometry in GeoLibre, including resources that have no geometry yet.

Open GeoLibre with the Arches plugin

Then open Plugins → Installed → Arches and sign in with your Arches address. Nothing is installed: it runs in your browser.

Before you sign in

This preview works with Arches 8.2, including fixes still in review. Which Arches to use explains what your instance needs. An Arches admin also needs to:

  • serve Arches over HTTPS: browsers block this page from reaching plain-HTTP addresses;
  • add https://fargeo.github.io to CORS_ALLOWED_ORIGINS in Arches' settings;
  • set up sign-in for the plugin, as described in Trying the plugin with your own Arches.

Use it in another GeoLibre

In GeoLibre Desktop or another GeoLibre site, open Settings → Manage Plugins → Settings, then either:

  • add the manifest URL https://fargeo.github.io/arches-geolibre/plugin.json; or
  • download arches-geolibre.zip and choose it under Install from file.
